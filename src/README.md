# Site source

The repo root holds the **generated** site that GitHub Pages serves. This
folder holds the **source** it is generated from. Edit here, never the root.

```
build.py          one HTML template + a PAGES list -> generates every page
style.css         the whole design system, one source of truth
pages/*.html      content fragments, one per page (no <head>, no nav)
pages/_book.html  the full book promo block, home page only
cover.jpg         book cover, copied into the build
cover2.jpg        book 2 cover, copied into the build
```

## Build and deploy

```sh
cd src
python3 build.py          # writes src/out/
cp -r out/. ..            # copy the generated site to the repo root
cd .. && git add -A && git commit -m "..." && git push origin HEAD:main
```

GitHub Pages deploys `main` automatically, usually within a minute.

## Adding a page

1. Write the content as an HTML fragment in `pages/<name>.html` — sections
   only, no `<head>` and no nav; the template supplies those.
2. Add an entry to the `PAGES` list in `build.py`: `slug`, `file`, `nav`
   label, `title`, `h1`, `standfirst`, meta `desc`, and the one-line `card`
   text used in other pages' "More reference charts" grid.
3. Run `python3 build.py` and deploy as above.

Nav, cross-links, sitemap, canonical URLs and Open Graph tags are all
generated, so no existing page needs editing when another is added.

## Things that must keep working

- **Page URLs** — every one is already live in published Pinterest pins. A
  changed path is a dead pin.
- **`CNAME`** in the repo root binds the custom domain rosiepaynecrochet.com.
  `build.py` regenerates it; do not delete it.
- **Pinterest verification meta tag** on every page
  (`p:domain_verify`) — generated by the template.
- **Cloudflare Web Analytics snippet** in every page's `<head>` — the only
  traffic data this site has. It is a manual JS snippet because the
  Cloudflare zone is DNS-only (unproxied), so automatic injection never
  fires.
- **Open Graph and canonical tags** — Pinterest Rich Pins depend on them.
- **Print styles** — every chart page has a Print button, and printed output
  includes the full page with nav, book promo and colour stripped.
- **Light and dark mode**, via CSS custom properties plus explicit
  `data-theme` overrides.
- **The two calculators** on `/calculators/` are vanilla JS reading specific
  input IDs. Restyle freely; do not break the maths or rename the IDs.

## Hosting, for the avoidance of confusion

- **GitHub Pages** hosts the site (repo `rosiepaynecrochet.github.io`, `main`, root).
- **Cloudflare** is registrar + DNS + Web Analytics only. All DNS records are
  "DNS only" (grey cloud); turning the orange proxy on breaks GitHub's SSL
  certificate.
